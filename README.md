# 🐾 科学铲屎官——营养 × 洗护 × 零食玩具

> 合法·科学·一站式的宠物AI管家 | Scientific Pet Care Assistant | TRAE SOLO Skill

## 📖 简介

科学铲屎官是一位融合国际营养标准（AAFCO/NRC/FEDIAF）与中国国标（GB/T 31216、GB/T 31217、NY/T 4838-2025、NY/T 4839-2025）的宠物营养与日常护理智能助手，覆盖猫、狗、兔子、仓鼠、龙猫、豚鼠、蜜袋鼯、鹦鹉、柯尔鸭、观赏鸡、宠物猪、矮脚马等家庭及庭院宠物。

**核心信条**：先算数据再开口，讲清原理再建议，安全永远是底线。

## 🎯 七大核心模式

| 模式 | 名称 | 核心能力 | 创新点 |
|------|------|----------|--------|
| 🍽️ 模式一 | 营养评估与饮食方案 | RER/DER计算+分阶段营养+宠粮对比+选粮避坑 | 2026新国标适配（NY/T 4838/4839） |
| 🐶 模式二 | 犬类专属养护 | 分品种/体型/毛发膳食+洗护+零食+玩具 | 六大毛发类型精准洗护 |
| 🐱 模式三 | 猫咪专属养护 | 纯肉食营养+长/短/卷毛洗护+化毛零食 | 牛磺酸红线+百合花致命警示 |
| 🐰 模式四 | 小宠异宠专区 | 兔/仓鼠/龙猫/豚鼠/蜜袋鼯/鹦鹉 | 禁水洗物种专项+VC需求 |
| 🏡 模式五 | 庭院宠物专区 | 柯尔鸭/观赏鸡/宠物猪/矮脚马 | 蹄部护理+饲养法规提醒 |
| 🧴 模式六 | 洗护美容与安全 | 品种洗护+天然配方+家庭修剪+红绿灯 | GB/T 43839+QB/T 4524国标依据 |
| 🍪 模式七 | 零食工坊与玩具DIY | 功能零食(5类)+磨牙用品+废物利用玩具 | 功效分类+14种禁忌食材红线 |

## 🌟 创新亮点

- 🆕 **2026新国标首发适配** — NY/T 4838处方粮+NY/T 4839冻干标准，选粮指导有法可依
- 🧴 **天然洗护DIY配方** — 燕麦洗毛液/苹果醋去油/椰子油护发素等6款家庭配方
- 🍪 **功能零食5大分类** — 美毛/磨牙/肠胃/补钙/训练，每款标注配比+功效+保存+喂食量
- 🧸 **废物利用玩具DIY** — 猫7款+狗7款+小宠6款，零成本+5分钟制作
- 🔴 **14种禁忌食材红线** — 巧克力/葡萄/洋葱/木糖醇等，每次输出强制提醒
- ⚖️ **物种合规筛查** — 白名单/黑名单自动判断，野生动物100%拒绝
- 📊 **个性化营养趋势** — 肠道微生物组/功能性原料/可持续蛋白等2026前沿
