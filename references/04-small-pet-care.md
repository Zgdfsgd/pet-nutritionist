# 小宠异宠养护指南

## 一、兔子（垂耳兔、侏儒兔等）

纯草食动物，拥有发达的盲肠，天生为处理高纤维、低能量草料而设计。

### 膳食方案
| 饮食组成 | 比例 | 说明 |
|----------|------|------|
| 干草（提摩西草等） | 无限量供应（约70%） | 核心主食，磨牙+维持肠道菌群+预防毛球症 |
| 新鲜蔬菜 | 约10-15% | 深色叶菜为主（油麦菜、芹菜叶、香菜等），每日约1杯/2kg体重 |
| 兔粮（颗粒） | 约5-10% | 每日约1/8-1/4杯/每5磅体重，选高纤维（≥18%粗纤维）配方 |
| 新鲜水果 | 仅作零食（≤5%） | 苹果、草莓、蓝莓等，去核去籽，每次不超过1茶匙 |

### 核心禁忌
高淀粉食物（面包、米饭、饼干）→ 致死性肠毒血症；生豆类、洋葱、大蒜、巧克力、牛油果

### 洗护要点
- **严禁水洗**：兔子受惊可致心脏骤停
- 局部脏污：蘸温水棉球或无香精宠物干洗泡沫擦拭
- 梳毛：每日1次，重点腋下/腹部/臀部，预防毛球症
- 修剪：仅修剪脚底毛、肛周过长毛发

### 零食与磨牙
| 零食 | 食材 | 功效 |
|------|------|------|
| 西兰花燕麦饼 | 焯水西兰花50g+燕麦粉30g | 高纤维助消化 |
| 香蕉红薯磨牙块 | 熟香蕉20g+红薯泥30g+燕麦片10g | 天然甜味磨牙 |
| 蒲公英叶脆片 | 新鲜蒲公英叶 | 清热解毒 |
| 苹果干 | 苹果切片（去核去籽） | 磨牙+补水 |

### DIY玩具
| 玩具 | 材料 | 核心乐趣 |
|------|------|----------|
| 提摩西草球 | 提摩西草+麻绳 | 啃咬/磨牙/推滚 |
| 纸筒隧道 | 保鲜膜筒芯/卫生纸筒芯 | 探索/躲藏/穿梭 |
| 苹果枝磨牙棒 | 苹果树枝（无农药） | 啃咬/磨牙 |
| 挖沙盘 | 塑料盒+宠物专用沙 | 挖掘/觅食/刨沙 |

## 二、龙猫

纯草食动物，对粗纤维需求高于兔子（可达35%），8颗牙齿终身生长，必须靠大量咀嚼干草磨损。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 干草 | 无限量供应（提摩西草为主），占饮食75%以上 |
| 龙猫专用颗粒粮 | 每日约1-2汤匙（15-25g），蛋白质16-20%、粗纤维≥18% |
| 零食 | 极少量：干玫瑰花瓣、干苹果片（不含硫熏） |

### 核心禁忌
高水分蔬果→腹胀/腹泻；坚果、种子→脂肪过高易致肝损伤；任何含糖零食→致命性消化紊乱

### 洗护要点
- **严禁水洗**：龙猫毛发极密，水洗后难以吹干，易致真菌感染
- 唯一正确清洁方式：沙浴（专用浴沙，敞口浅盆，夏季每天1次，冬季每2天1次）

### DIY玩具
| 玩具 | 材料 | 核心乐趣 |
|------|------|----------|
| 提摩西草球 | 提摩西草+麻绳 | 啃咬/磨牙 |
| 悬挂秋千 | 木棍(直径2cm)+麻绳 | 攀爬/平衡/休息 |
| 酒瓶塞啃咬乐园 | 天然软木塞3个+棉绳 | 天然磨牙 |

## 三、仓鼠（金丝熊、花枝鼠等）

杂食动物，营养核心为高蛋白、中高脂肪、低碳水化合物。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 仓鼠专用主粮 | 每日约10-12g（约1-2汤匙），蛋白质≥18%、脂肪5-10% |
| 新鲜蔬菜 | 少量，每周2-3次（黄瓜、胡萝卜、西兰花等），每次指甲盖大小 |
| 动物蛋白补充 | 每周1次：水煮蛋清一小块、面包虫1-2条 |
| 水果 | 极少量零食（苹果、蓝莓等），去核去籽 |

### 核心禁忌
柑橘类（酸性过强）、洋葱、大蒜、巧克力、牛油果、生豆类

### DIY玩具
| 玩具 | 材料 | 核心乐趣 |
|------|------|----------|
| 纸巾筒迷宫 | 纸巾筒+剪刀+零食 | 啃咬+觅食 |
| 冰棒棍攀爬墙 | 50根冰棒棍+食品级木胶 | 攀爬+探索 |
| 纸巾筒迷宫城堡 | 3个纸巾筒+无油墨牛皮纸 | 钻探天性 |
| 纸杯叠叠乐 | 3-4个无涂层纸杯+零食 | 益智挑战 |

## 四、豚鼠（荷兰猪）

与兔子同属草食动物，但**自身无法合成维生素C**，必须每日从食物中补充。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 干草 | 无限量供应（提摩西草为主） |
| 豚鼠专用颗粒粮 | 每日约1/8杯，必须选添加VC的专用配方 |
| 新鲜蔬菜（VC来源） | 每日约1杯：甜椒（VC含量极高）、西兰花、羽衣甘蓝、香菜 |
| 水果 | 少量（每周2-3次）：橙子、猕猴桃等VC丰富的水果 |

### VC最低需求
成年豚鼠每日约10-30mg/kg体重，孕期需加倍

### 核心禁忌
土豆、洋葱、韭菜、巧克力、牛油果、生豆类、大黄

### DIY玩具
| 玩具 | 材料 | 核心乐趣 |
|------|------|----------|
| 干草方块挑战 | 小纸箱+干草+零食 | 探索+磨牙 |
| 酸奶盒漏食球 | 酸奶盒+美工刀+绳子 | 互动取食 |
| 蔬菜串 | 胡萝卜片/苹果片+麻绳 | 啃咬/觅食/拉伸 |

## 五、蜜袋鼯

杂食性有袋动物，自然食谱为花蜜、树液、昆虫和小型脊椎动物。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 蜜袋鼯专用配方粮 | 基础主食，选择高蛋白低脂肪配方 |
| 蛋白质来源 | 每日补充：水煮鸡胸肉、水煮蛋、面包虫 |
| 蔬果 | 每日适量：苹果、葡萄、甜瓜、玉米（少量） |
| 花蜜/树液替代 | 蜂蜜水（极稀）或专用花蜜粉 |

### 核心禁忌
巧克力、洋葱、大蒜、牛油果、高脂食物、含咖啡因食物

### 洗护要点
- 不建议水洗，可用无香精湿巾局部清洁
- 梳毛：每周1-2次，用软毛刷轻柔梳理

## 六、观赏鹦鹉（虎皮、玄凤、牡丹等人工繁育品种）

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 鹦鹉专用混合粮 | 以谷物种子为基础，搭配滋养丸 |
| 新鲜蔬菜 | 每日适量：西兰花、胡萝卜、甜椒 |
| 新鲜水果 | 少量：苹果（去籽）、葡萄、浆果 |
| 矿物质块/墨鱼骨 | 自由啄食，补钙+磨喙 |

### 核心禁忌
牛油果（对鸟类剧毒）、巧克力、洋葱、大蒜、咖啡因、酒精、水果核（含氰化物）

### 洗护要点
- 提供浅水盆供其自行沐浴
- 可用喷雾瓶轻喷水雾
- 严禁使用吹风机（噪音+高温应激）

### DIY玩具
| 玩具 | 材料 | 核心乐趣 |
|------|------|----------|
| 纸筒啃咬串 | 卫生纸筒+棉绳 | 啃咬/撕扯 |
| 苹果枝攀爬架 | 苹果枝+麻绳 | 攀爬/啃咬 |
| 吸管零食串 | 吸管+棉线+小宠零食 | 啃咬+取食 |
