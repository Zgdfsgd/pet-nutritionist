# 营养基础与能量计算

## 一、六大营养素

| 营养素 | 功能 | 猫狗需求特点 |
|--------|------|-------------|
| 蛋白质 | 肌肉/酶/激素/免疫 | 猫需求高于狗，需动物蛋白 |
| 脂肪 | 能量/必需脂肪酸/脂溶性维生素载体 | 猫需花生四烯酸（仅动物来源） |
| 碳水化合物 | 能量/膳食纤维 | 猫利用率低，狗可适度利用 |
| 维生素 | 代谢辅酶/抗氧化/骨骼 | 猫需预成型VA（动物来源），无法从β-胡萝卜素转化 |
| 矿物质 | 骨骼/神经/体液平衡 | 钙磷比1.2:1~1.4:1为黄金比例 |
| 水 | 体温调节/代谢/排泄 | 猫天生饮水少，湿粮补水重要 |

## 二、能量需求计算

### 静息能量需求（RER）
RER(kcal/天) = 70 × (体重kg)^0.75

常用体重速查：
| 体重(kg) | RER(kcal) |
|----------|-----------|
| 2 | 118 |
| 3 | 160 |
| 4 | 200 |
| 5 | 234 |
| 7 | 301 |
| 10 | 396 |
| 15 | 534 |
| 20 | 662 |
| 25 | 783 |
| 30 | 899 |
| 40 | 1122 |
| 50 | 1332 |

### 每日能量需求（DER）
DER = RER × 生命阶段系数

| 生命阶段 | 系数 |
|----------|------|
| 幼犬/幼猫（0-4月龄） | 3.0 |
| 幼犬/幼猫（4月龄-成年） | 2.0 |
| 成年犬（未绝育） | 1.8 |
| 成年犬（已绝育） | 1.6 |
| 成年猫（未绝育） | 1.4 |
| 成年猫（已绝育） | 1.2 |
| 老年犬/猫（活动正常） | 1.4-1.6 |
| 老年犬/猫（活动减少） | 1.1-1.4 |
| 孕期（后1/3） | 1.8-2.0 |
| 哺乳期 | 2.0-4.0（依仔数调整） |
| 减重目标 | 1.0 × RER（用目标体重） |
| 增重目标 | 1.4-1.8 × RER（用当前体重） |

### 每日喂食量换算
- 商业宠粮：日喂食量(g) = DER(kcal) ÷ 宠粮代谢能(kcal/g)
- 自制/鲜食：根据DER和AAFCO/国标营养需求推荐食材搭配比例

## 三、BCS体况评分表（9分制）

| 分数 | 描述 | 判断方法 |
|------|------|----------|
| 1 | 极度消瘦 | 肋骨/脊椎/髋骨明显突出，无脂肪覆盖 |
| 2-3 | 偏瘦 | 肋骨易触及，腰线明显 |
| 4-5 | 理想 | 肋骨可触及但有薄脂肪层，腰线可见 |
| 6-7 | 偏胖 | 肋骨难触及，腰线不明显 |
| 8-9 | 肥胖 | 肋骨无法触及，无腰线，脂肪堆积明显 |

引导用户自评：从上方俯视看腰线，从侧面看腹部上收程度。

## 四、猫狗核心营养指标（干物质基础）

### 犬营养指标
| 营养素 | 幼犬（生长期） | 成犬（维持期） |
|--------|--------------|--------------|
| 粗蛋白 | ≥22% | ≥18% |
| 粗脂肪 | ≥8% | ≥5% |
| 钙 | 1.0-2.5% | 0.4-1.0% |
| 磷 | 0.8-1.6% | 0.3-0.8% |
| 钙磷比 | 1.2:1~1.4:1 | 1.2:1~1.4:1 |

### 猫营养指标
| 营养素 | 幼猫（生长期） | 成猫（维持期） |
|--------|--------------|--------------|
| 粗蛋白 | ≥38% | ≥30% |
| 粗脂肪 | 15-20% | 15-20% |
| 钙 | 1.0-1.5% | 0.6-1.0% |
| 磷 | 0.8-1.2% | 0.5-0.8% |
| 钙磷比 | 1.2:1~1.4:1 | 1.2:1~1.4:1 |
| 牛磺酸（干粮） | ≥0.2% | ≥0.2% |
| 牛磺酸（湿粮） | ≥0.3% | ≥0.3% |

**特别强调**：猫是专性肉食动物，无法自身合成牛磺酸和精氨酸，绝不可为猫推荐素食喂养方案。犬是兼性肉食动物，可以消化部分碳水化合物，但高质量动物蛋白仍是首选。

## 五、宠粮类型对比

| 类型 | 水分 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| 膨化干粮 | 6-10% | 经济实惠、保质期长、易储存 | 含水量低（需确保饮水充足） | 多宠家庭、预算有限 |
| 冻干生食 | 3-5% | 高蛋白、高适口性、营养保留好 | 单价高、复水需时间 | 挑食宠物、追求高蛋白 |
| 主食湿粮/罐头 | 75-85% | 含水量高（有利泌尿道）、适口性好 | 开封后保存期短、单价较高 | 饮水量不足的猫、老年宠物 |
| 鲜食/自制 | 60-75% | 食材可溯源、新鲜度高 | 需精准配比（自配极易缺钙/B1/牛磺酸） | 有时间和知识储备的主人 |
| 烘焙粮 | 8-10% | 低温烘焙保留营养、颗粒酥脆 | 价格较高 | 追求天然营养的宠物主 |

## 六、换粮过渡方案（7-10天）

| 天数 | 新粮比例 | 旧粮比例 |
|------|----------|----------|
| 第1-2天 | 25% | 75% |
| 第3-4天 | 50% | 50% |
| 第5-6天 | 75% | 25% |
| 第7天起 | 100% | 0% |

肠胃敏感宠物延长至10-14天。观察指标：粪便成型度、食欲、精神状态。出现持续软便或呕吐应暂停换粮并就医。

## 七、2025-2026宠物营养趋势

1. **个性化/定制化营养** — 基于品种、年龄、基因检测的精准配方
2. **肠道微生物组** — 益生菌/益生元/后生元，肠道菌群平衡与免疫代谢密切相关
3. **功能性原料** — 功能性脂肪酸、抗氧化物、关节支持成分
4. **人类级食材** — 消费者追求可溯源、人用级安全标准
5. **可持续蛋白** — 昆虫蛋白、细胞培养肉等新型蛋白源
