# 庭院宠物养护指南

## 一、柯尔鸭

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 水禽专用颗粒饲料 | 自由采食，蛋白质含量15-18%（育成期） |
| 新鲜蔬菜/水草 | 每日适量：浮萍、切碎菜叶等 |
| 干净饮水 | 需水盆足够深（能淹没鸭喙），用于清洁鼻孔和眼睛 |

### 核心禁忌
干燥粉状饲料（易呛入气管）；发霉饲料；高盐人类食物；洋葱、巧克力

### 洗护要点
- 需提供足够深的水盆供其洗澡和清洁鼻孔
- 保持水质清洁，每日更换
- 户外饲养需遮阳避雨

### 庭院玩具
- 浅水盆戏水（天然乐趣）
- 蔬菜漂浮物（白菜叶放水面供啄玩）

## 二、观赏鸡

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 鸡专用颗粒料/粉料 | 自由采食，按年龄选育雏料/生长期料/产蛋期料 |
| 新鲜蔬菜/青草 | 每日适量（占饮食10-20%） |
| 钙质补充（产蛋期） | 牡蛎壳粉/石灰石碎粒，自由啄食 |
| 粗砂/细石子 | 帮助研磨嗉囊中的食物 |

### 核心禁忌
生豆类（含血凝素）；发霉饲料；高盐厨余；洋葱/大蒜（影响蛋的风味）；巧克力、牛油果

### 洗护要点
- 鸡会自行沙浴清洁羽毛
- 提供干燥沙土区域供其沙浴
- 雨天需有避雨棚

### 庭院玩具
- 沙浴盆（浅盆装干净沙土）
- 蔬菜悬挂串（白菜/生菜悬挂供跳跃啄食）
- 栖木攀爬架（不同高度的木棍）

## 三、宠物猪（迷你香猪等）

杂食动物，消化系统与人类相似，但极易发胖。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 宠物猪专用颗粒粮 | 每日约1-2%体重（如20kg猪约200-400g），分2-3餐 |
| 新鲜蔬菜 | 每日大量（占饮食50%以上）：南瓜、黄瓜、胡萝卜、菠菜 |
| 水果 | 少量（每日不超过10%）：苹果、蓝莓等 |
| 干草/牧草 | 可适量供应，增加纤维和饱腹感 |

### 核心禁忌
高盐/高糖/高脂人类食物；巧克力、洋葱、大蒜、生豆类；发霉饲料

### 洗护要点
- 可水洗，需使用温和宠物香波
- 蹄甲过长需由专业人士修剪
- 皮肤褶皱处需定期清洁防感染

### 庭院玩具
- 漏食球（宠物猪专用或大号狗用漏食球）
- 泥坑（猪天性喜欢拱土，提供安全泥坑满足天性）
- 旧毛巾/毯子（供其拱和窝着休息）

## 四、矮脚马（设特兰矮马等）

纯草食动物，属后肠发酵消化系统，需持续采食粗纤维。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 粗饲料（干草/牧草） | 每日干草摄入量约为体重的1.5%-2% |
| 精料补充 | 根据活动量补充，一般成年矮马少量或无需精料 |
| 专用矿物质块/盐砖 | 自由舔食，补充微量元素 |
| 干净饮水 | 每日需充足干净饮水（15-30L） |

### 核心禁忌
发霉饲料（产生霉菌毒素，严重可致死）；过量精料/谷物（导致蹄叶炎和肠绞痛）；草坪修剪后的草屑（快速发酵产气）；牛用饲料（铜含量过高）

### 洗护要点
- 使用硬毛刷顺毛梳理
- 蹄部护理是重中之重：需定期清理蹄底并请专业修蹄师修蹄（每6-8周）
- 夏季可水洗，冬季注意保暖

### ⚠️ 饲养前必读
矮脚马不是"省心宠物"：
- 城市饲养需办理相关许可证
- 需每6-8周专业修蹄
- 属群居动物不宜单独饲养
- 需要较大活动空间
- 如需了解完整饲养法规，请咨询当地林业/农业部门

### 庭院玩具
- 漏食球（马用慢食球）
- 悬挂舔砖（矿物质+消磨时间）
- 大号球（供推滚玩耍）

## 五、侏儒羊

纯草食反刍动物。

### 膳食方案
| 饮食组成 | 说明 |
|----------|------|
| 干草/牧草 | 自由采食，占饮食主体 |
| 专用羊颗粒料 | 适量补充 |
| 矿物质舔砖 | 自由舔食 |
| 干净饮水 | 每日充足 |

### 核心禁忌
发霉饲料；过量谷物；含铜量高的饲料（羊对铜敏感）；有毒植物（杜鹃、夹竹桃等）

### 洗护要点
- 硬毛刷顺毛梳理
- 蹄部定期修剪（每6-8周）
- 春季剪毛（长毛品种）

### ⚠️ 饲养提醒
需确认当地政策，办理相关许可证。属群居动物，不宜单独饲养。
